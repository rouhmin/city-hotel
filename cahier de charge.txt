2. Objectifs du site

Le site doit :

présenter City Hôtel de manière professionnelle ;
mettre en valeur les chambres ;
afficher les tarifs ;
présenter les équipements ;
montrer les photos réelles de l'hôtel ;
présenter l'emplacement ;
permettre de contacter rapidement l'hôtel ;
faciliter les demandes de réservation ;
être parfaitement adapté aux smartphones ;
donner une image élégante, moderne et haut de gamme.

Le site ne comportera pas de système de réservation avec disponibilité en temps réel, ni de paiement en ligne.

La réservation se fera par :

WhatsApp → Messenger → Appel téléphonique

26. Performance

Très important pour un site hôtelier avec beaucoup de photos.

Tu dois :

compresser les images ;
utiliser WebP quand possible ;
éviter les images énormes ;
lazy-load des images ;
ne pas mettre 10 animations lourdes en même temps ;
optimiser les photos avant de les intégrer.

Par exemple, une photo de téléphone de 5–10 Mo ne doit pas être directement mise sur le site.
